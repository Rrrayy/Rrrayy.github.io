## 设计细节记录

### 背景系统 V3（多层叠加，2026.06.11 重构，z-index 由底到顶）
1. 暖深灰渐变基底（bg_base）—— 径向渐变 + 线性渐变混合，#0a0a0f → #0e0e18 → #0a0a0f，不纯黑不伤眼
2. 极光光晕（aurora orbs）—— 2个柔和浮动渐变 blob（紫/蓝），blur(120px)，更克制
3. 细微网格纹理（bg_grid）—— 60px 间距，rgba(255,255,255,0.012)，参考 Linear / Vercel 斜线风格
4. 噪声纹理（noise overlay）—— SVG fractalNoise 滤镜，opacity 0.18
5. 鼠标追踪聚光灯（spotlight）—— 800px 径向渐变跟随鼠标，紫色微光

### 组件样式（V3 右对齐布局）
- 整体布局：所有模块 max-w-2xl ml-auto（右侧对齐），Hero 区内容 text-right
- 头像: 紫色光晕边框 + hover 增强，右侧对齐
- 名字: gradient_name 紫蓝渐变色（#e0d5ff → #a78bfa → #818cf8）
- 社交链接: 水平排列，hover 向右微移（translateX 3px）+ 变紫色
- CTA 按钮: 紫色边框 + 箭头图标 Lucide arrow-right，hover 变亮
- 技能标签（tag_glow）: 伪元素渐变边框（紫蓝），暗色底，hover 上浮 + 光晕
- 模块容器（glass_section）: 深色毛玻璃 rgba(255,255,255,0.02) + backdrop-blur(24px) + 微白边框 + 内阴影
- 标题（section_title）: 右对齐 text-right，下划线装饰线右对齐
- 粘性导航栏（sticky_nav）: 深色毛玻璃 rgba(10,10,15,0.75)，7个导航项（含书架）
- 滚动进度条（scroll_progress）: 顶部 1.5px 紫蓝渐变细线
- ::selection: 紫色高亮

### 书架模块设计
- 4列网格（sm:4, 移动端2列），aspect-ratio:3/4 标准书比例
- 封面图 Open Library ISBN API 加载（异步 lazy loading）
- 加载失败自动显示渐变色 fallback（8种不同深色渐变区分书籍）
- hover 上浮 6px + 阴影加强
- 底部 shelf_plank 木板装饰线（6px高 + 渐变半透明 + 高光线）
- 统计小字 + 书籍图标，右对齐

### 交互效果
- 鼠标聚光灯跟随（800px 范围）
- 所有模块 Intersection Observer 渐入动画（fade + translateY 24px，加延迟变体）
- 社交链接 hover: translateX(3px) 向右 + 变紫色
- 导航链接 hover: 底部紫色指示线 scaleX 展开
- 导航自动高亮: 根据滚动位置自动切换 active
- 粘性导航栏: 向上滚动超过 hero 60% 出现，向下滚动隐藏
- 书架卡片 hover: translateY(-6px) + 大阴影
- 选中文本: 紫色背景高亮
