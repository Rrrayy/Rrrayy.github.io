## 1. 写博客文章

在 `blog/posts/` 目录下新建 `.md` 文件，格式如下：

```markdown
---
title: 智能指针入门
date: 2026-06-20
tags: C++, 内存管理
categories: 技术
---

# 智能指针入门

正文内容...

## unique_ptr

独占所有权的智能指针...

## shared_ptr

引用计数的智能指针...
```

**规则：**
- `---` 之间的部分是文章信息（frontmatter）
- `title` — 文章标题（必填）
- `date` — 日期（必填，格式 YYYY-MM-DD）
- `tags` — 标签，用英文逗号分隔
- `categories` — 分类

**支持的 Markdown 语法：**
- `# 标题` / `## 标题` / `### 标题`
- `**粗体**` / `*斜体*`
- `` `代码` `` / ` ```cpp ... ``` `（代码块）
- `> 引用`
- `- 列表项`
- `[链接文字](url)`
- `![图片说明](图片url)`
- `| 表格 | 语法 |`

## 2. 构建脚本（python build.py）

写完 Markdown 后，在项目根目录（`F:/r网站/v2/`）运行：

```bash
python build.py
```

**这个命令会做三件事：**

1. 扫描 `blog/posts/` 下所有 `.md` 文件
2. 为每篇文章生成独立的 `.html` 文件（如 `blog/posts/zhi-neng-zhi-zhen.html`）
3. 更新 `blog/posts/index.json`（博客列表用）

**什么时候要跑 build.py：**

| 场景 | 需要跑 build.py |
|------|:------:|
| 写了新文章 | ✅ |
| 修改了已有文章内容 | ✅ |
| 改了文章标题/日期/标签 | ✅ |
| 只改网站样式/布局 | ❌ |

**重要提醒：**
- 每次写完文章**必须跑一次** `python build.py`，否则新文章不会出现在博客列表里
- 中文章节会自动转成英文 URL（如「智能指针」→ `zhi-neng-zhi-zhen`）
- 构建脚本依赖 Python `markdown` 库（已安装）

## 3. 新增页面

如果想加一个新页面（如「关于我」），步骤：

1. 复制一份现有的页面做模板，比如 `roadmap.html`
2. 修改 `<title>` 和页面内容
3. 在 `nav_links` 里加上导航链接：
```html
<a href="about.html" class="nav_link">关于</a>
```
4. 其他页面的导航栏也要同步加这个链接（所有页面都要改）

**快捷方法：** 所有页面的导航栏结构相同，需要手动保持同步。

---

## 4. 修改导航栏

导航栏在每个页面的 `<nav class="site_nav">` 部分，需要手动同步修改以下文件：

| 页面 | 文件路径 |
|------|----------|
| 首页 | `index.html`（左侧面板底部 mini 导航） |
| 学习路线 | `roadmap.html` |
| 书架 | `bookshelf.html` |
| 留言板 | `guestbook.html` |
| 博客列表 | `blog/index.html` |
| 文章页 | `blog/post.html` |
| 构建模板 | `build.py` 中的 `PAGE_TPL` 变量 |

**注意：** `blog/index.html` 和 `blog/post.html` 在子目录中，链接要用 `../` 前缀。构建生成的文章页在 `blog/posts/` 下，链接要用 `../../` 前缀。

## 5. 主题切换

- 点击导航栏的太阳/月亮图标切换暗黑/明亮模式
- 设置保存在 `localStorage` 中，刷新后保持
- 首次访问自动跟随系统偏好
- 所有页面共享同一套 CSS 变量，主题切换全部同步

## 6. 上线部署

### 方案一：替换原网站（v2 转正）

```bash
# 备份原网站（可选）
cp F:/r网站/index.html F:/r网站/index.html.bak

# 把 v2 的内容复制到根目录（注意路径调整）
# blog/posts/ 下的文章链接需要改成 ../assets/ 而不是 ../../assets/
```

**注意事项：**
- v2 的 `index.html` 放在网站根目录
- `blog/index.html` 放在 `blog/` 子目录
- `blog/posts/*.html` 放在 `blog/posts/` 子目录
- `assets/` 在根目录
- 构建模板 `PAGE_TPL` 中的路径需要改为单层 `../`（当前为 `../../`）

### 方案二：子路径部署

把 `v2/` 整个目录推送到 `https://你的域名.com/v2/`。

## 7. 常见问题

**Q: 新写的文章在博客列表看不到？**
A: 忘了跑 `python build.py`，跑一下就好了。

**Q: 文章页样式不对？**
A: 检查路径：`blog/posts/xxx.html` 应该引用 `../../assets/css/style.css`。

**Q: 导航栏的"当前页高亮"不对？**
A: `main.js` 中根据 URL 文件名匹配 `nav_link` 的 `href`，确保 href 与文件名一致。

**Q: 首页留言板按钮没反应？**
A: 首页保留弹窗模式，需要 `guestbookOverlay` 元素在 DOM 中。如果重写了首页，确保包含了留言板弹窗 HTML。

**Q: 子页面主题切换按钮没用？**
A: 子页面用的是 `themeToggleNav`（导航栏内），首页用的是 `themeToggle`（右上角浮动）。
`main.js` 中会 fallback 查找两个 ID，其中一个存在即可。

**Q: 新增标签后要做什么？**
A: 跑 `python build.py`，标签云会自动更新。

**Q: 想改网站主色？**
A: 在 `assets/css/style.css` 开头的 `:root` 中修改 CSS 变量即可，所有页面同步生效。
