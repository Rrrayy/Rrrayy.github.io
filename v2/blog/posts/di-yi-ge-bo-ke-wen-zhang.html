第一个博客文章

嘿，这是我的第一篇博客文章。

为什么写博客

我一直想把学习过程中的思考和总结记录下来。以前在书上划线和记笔记，但那些都留在本子里，别人看不到，自己也很难回顾。

写博客的好处：

  • 整理思路 — 把知识用自己的话写出来，才是真的理解
  • 记录成长 — 几个月后回头看，能看到自己进步了多少
  • 分享交流 — 也许能帮到同样在学这些内容的同学

关于这个网站

这个网站完全是我手写的 HTML + CSS + JavaScript，没有用任何框架。配色是黑红撞色，90% 黑色打底，红色做点缀。

现在网站有了：首页、学习路线、书架、留言板、博客。

博客现在搭好了框架，后续会慢慢把我之前学的 C++、计算机系统、算法这些内容整理成文章发出来。

计划写的内容

  1. C++ — 从 OOP 到 STL 到现代 C++ 特性
  2. 计算机系统 — CS:APP 读书笔记
  3. 算法 — LeetCode 刷题记录和思路
  4. 操作系统 — 进程、内存、并发
  5. 网络 — TCP/IP、HTTP、网络编程

结语

保持学习，保持输出。

Stay hungry, stay foolish.
